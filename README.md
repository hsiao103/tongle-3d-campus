# 同樂國小 3D 校園（v282）

宜蘭縣員山鄉同樂國小的可步行 3D 校園。單一 HTML 檔，使用 Three.js r128，支援電腦、手機／平板與 VR 頭盔（WebXR）。

## 直接使用

- 用瀏覽器開啟 `index.html`（內容與 `school.html` 相同），需要網路載入 Three.js 與字型。
- 若啟用 GitHub Pages，網址根目錄即可直接開啟。

## 功能摘要

- 視角：鳥瞰、俯視穿透、第三人稱、第一人稱。
- 風格：一般、2D 線稿、像素。日／夜切換。
- 地圖範圍 200 × 200 公尺，以校園為中心；範圍外裁切。
- 開場畫面可選男生／女生角色，並有「操作說明」與「常見問題」分頁。
- 手機／平板：左虛擬搖桿移動、單指拖曳轉視角、右側「跑」（開關）與「跳」按鈕；鳥瞰時用搖桿平移、拖曳旋轉與俯仰。
- 電腦：WASD 移動、Shift 跑、空白鍵跳、滑鼠拖曳轉視角。
- VR（Quest 等）：搖桿移動與轉向，按鍵可傳送、切換日夜。

## 重新建置

在本資料夾執行 `bash build.sh`（需要 node），會把 `part*.js` 與 `vendor/` 合併成 `school.html`，並以 `node --check` 檢查語法。
建置完成後若要用於 GitHub Pages，請將 `school.html` 複製為 `index.html`。

## 檔案結構

- `part1.html`：頁面骨架、CSS、介面元件（選單、開場、搖桿、跑／跳鈕）
- `part2.js`：場景、材質、日夜；`part2d.js`：像素風與線稿後處理；`part2e.js`：夜間教室燈光
- `part3a/3b/3c.js`：建築與校園場景（`3b` 含地圖邊界與道路）
- `part4.js`：視角切換、相機、移動與碰撞、虛擬搖桿
- `part5.js`：地點、導覽與開場說明；`part6.js`：VR 與其他功能；`part7.js`：角色、NPC、點地移動、電梯
- `vendor/`：GLTFLoader、SkeletonUtils、角色資料與 glb、`three.r128.min.js`（離線建置用）

## 已知狀態

- 手機／平板與 VR 的操作僅經模擬測試，尚未在實機完整驗證。
- 部分建築材質在特定角度可能有閃爍（z-fighting），尚待回報位置後處理。
- 夜間教室燈光為發光材質，非真實光源。

## 設計原則

模型不旋轉（北為 −z）；停車場不加遮棚；不加農會；B–C 的ㄇ形開口朝北。
