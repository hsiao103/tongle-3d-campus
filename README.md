# 同樂國小 3D 校園（v286）

宜蘭縣員山鄉同樂國小的可步行 3D 校園。單一 HTML 檔，使用 Three.js r128，支援電腦、手機／平板與 VR 頭盔（WebXR）。

## 直接使用
- 啟用 GitHub Pages（Settings → Pages → Branch: main / root），網址根目錄即開啟 `index.html`。
- 或用瀏覽器開啟 `index.html`（內容與建置出的 `school.html` 相同）。需要網路載入 Three.js 與字型。

## 功能摘要
- 視角：鳥瞰、俯視穿透、第三人稱、第一人稱。
- 風格：一般、2D 線稿、像素。日／夜切換。
- **主題**：一般、萬聖節、端午節、聖誕節、農曆春節（見下）。
- 地圖範圍 200 × 200 公尺，以校園為中心；範圍外裁切。
- 開場可選男生／女生角色，有「操作說明」與「常見問題」。
- 搜尋教室與地點，黃色箭頭自動導引；校園 NPC。
- 手機／平板：左虛擬搖桿移動、單指拖曳轉視角、右側「跑」與「跳」；電腦：WASD、Shift 跑、空白鍵跳。
- VR（Quest 等）：搖桿移動與轉向，按鍵可傳送、切換日夜。

## 主題
右上選單「主題」可切換；每個主題含布置、專屬天色與日夜變化。
| 主題 | 內容 |
|---|---|
| 萬聖節 | 南瓜、骷髏頭、墓碑、蝙蝠、幽靈、小妖怪、紫橘天空 |
| 端午節 | 屈原、白蛇、青蛇、法海、蜈蚣、粽子、艾草、龍舟 |
| 聖誕節 | 聖誕樹、聖誕老公公與馴鹿雪橇、雪人、拐杖糖、禮物、飄雪，地面與屋頂覆雪 |
| 農曆春節 | 燈籠串、春聯門與倒福、舞獅、舞龍、金桔盆栽、紅包、煙火 |

### 主題選擇優先順序
1. 網址參數 `?theme=halloween|duanwu|christmas|newyear|default`
2. 與 `index.html` 同層的 `theme.json`（僅 http/https 時讀取，逾時 2.5 秒）：
   `{"theme":"halloween","from":"2026-10-20","until":"2026-11-01"}`（範例見 `theme.example.json`）；期間外自動回到一般。
3. 日期排程：`part8.js` 內 `THEME_CFG.auto=true` 才啟用（預設關閉）。
4. 預設：一般。

農曆節日（端午、春節）日期每年不同，請用 `theme.json` 指定起訖日。

## 重新建置
在本資料夾執行 `bash build.sh`（需要 node），會把 `part*.js` 與 `vendor/` 合併成 `school.html`，以 `node --check` 檢查語法，並複製為 `index.html`。

## 檔案結構
- `part1.html`：頁面骨架、CSS、介面元件
- `part2.js`：場景、材質、日夜；`part2d.js`：像素風與線稿；`part2e.js`：夜間教室燈光
- `part3a/3b/3c.js`：建築與校園場景
- `part4.js`：視角、相機、移動與碰撞、搖桿；`part5.js`：地點、導覽、開場說明
- `part6.js`：VR；`part7.js`：角色、NPC、點地移動、電梯
- `part8.js`：主題系統（切換、排程、各主題內容）
- `vendor/`：GLTFLoader、SkeletonUtils、角色資料與 glb、`three.r128.min.js`（離線建置用）

## 已知狀態
- 手機／平板與 VR 僅經模擬測試，尚未在實機完整驗證。
- 部分建築材質在特定角度可能有閃爍（z-fighting），尚待回報位置後處理。
- 主題為原創布置；其中端午、春節日期需手動設定。

## 設計原則
模型不旋轉（北為 −z）；停車場不加遮棚；不加農會；B–C 的ㄇ形開口朝北。
